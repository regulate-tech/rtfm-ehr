Welcome to the EHR Demonstrator

This application demonstrates interactions between a Patient Master Index (PMI), an openEHR server (EHRBase), and different user roles.

Select a role from the navigation above to explore the features.

Setup Steps Overview:

  1. Ensure Docker & Python are installed.
  2. Run `docker-compose -f ehrbase.yml up -d` to start EHRBase & Postgres.
  3. Create & activate a Python virtual environment (`python -m venv venv`, `source venv/bin/activate`).
  4. Install dependencies: `pip install -r requirements.txt`.
  5. Create the `.env` file with a `SECRET_KEY`.
  6. Run `python setup_pmi_database.py` to create the PMI database/table.
  7. Run `python install_templates.py` to upload the openEHR templates to EHRBase.
  8. (Optional) Run `python add_pmi_records.py ` to add fake patients.
  9. Run the web app: `flask run`.

See the `README.md` file for detailed instructions.
